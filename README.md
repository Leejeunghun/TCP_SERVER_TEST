# TCP 통신 테스트 서버

Python TCP 서버 + 웹 대시보드. 클라이언트와의 TCP 연결이 끊어졌는지(또는 응답 없이 멈췄는지) 실시간으로 확인하기 위한 통신 테스트 도구입니다.

## 구성 파일

| 파일 | 설명 |
|---|---|
| `server.py` | TCP 서버 코어. 접속한 클라이언트별로 연결/유휴/끊김 상태, 송수신 바이트·횟수, 최근 송수신 로그(hex+텍스트)를 추적 |
| `app.py` | Flask + Socket.IO 웹 앱. TCP 서버 이벤트를 웹소켓으로 대시보드에 실시간 푸시 |
| `templates/index.html` | 대시보드 페이지 |
| `static/dashboard.js` | 대시보드 클라이언트 로직 (실시간 갱신, 테스트 전송, 로그 토글) |
| `static/style.css` | 대시보드 스타일 |
| `test_client.py` | 실제 장비 없이 연결→송신→종료 사이클을 흉내내는 테스트용 클라이언트 |
| `requirements.txt` | 의존 패키지 목록 |

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python app.py --port 44202 --idle-timeout 30 --web-port 5000
```

브라우저에서 `http://localhost:5000` 접속.

### 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--host` | `0.0.0.0` | TCP 서버가 바인딩할 호스트 |
| `--port` | `44202` | TCP 서버 포트 |
| `--idle-timeout` | `30` | 이 시간(초) 이상 데이터가 없으면 "응답없음"으로 표시 |
| `--web-host` | `0.0.0.0` | 대시보드 웹 서버 호스트 |
| `--web-port` | `5000` | 대시보드 웹 서버 포트 |

## 대시보드 사용법

- **상태 배지**: 연결됨(초록) → 응답없음(노랑, idle 타임아웃 초과) → 끊김(빨강, 소켓 종료)
- **테스트 전송**: 클라이언트 행의 입력창에 문자열을 입력하고 전송하면 서버가 해당 클라이언트로 그대로 보냄 (왕복 테스트용)
- **로그 보기**: 클라이언트별 최근 송수신 내역을 hex + 텍스트로 확인
- **이벤트 로그**: 모든 클라이언트의 연결/응답없음/끊김/송수신 이력이 하단에 실시간으로 누적
- **끊긴 항목 지우기**: 화면에서만 끊긴 클라이언트 행 제거 (서버 상태에는 영향 없음)

## 테스트용 가짜 클라이언트

실제 장비 없이 대시보드 동작을 확인하려면:

```bash
python test_client.py --host 127.0.0.1 --port 44202 --interval 5 --hold 1
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--count` | `0` (무한) | 연결 사이클 반복 횟수 |
| `--interval` | `5.0` | 연결 사이클 사이 대기 시간(초) |
| `--hold` | `1.0` | 연결 유지 후 종료하기까지 대기 시간(초) |

## 참고

이 서버는 프로토콜을 해석하지 않는 범용 TCP 모니터입니다. 어떤 클라이언트든 접속해 바이트를 보내면 연결 상태와 원문 데이터를 그대로 확인할 수 있습니다.
